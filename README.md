# 🌐 Portfólio Pessoal

Este é o repositório do meu **portfólio web**, desenvolvido para apresentar meus projetos, habilidades e experiências de forma clara e interativa.

🔗 **Link para acessar:** [marinaldo-neto.github.io/portfolio](https://marinaldo-neto.github.io/portfolio/)

---

## 📌 Objetivo

O objetivo deste projeto é centralizar e exibir minhas principais informações como desenvolvedor, reunindo:
- Apresentação pessoal
- Projetos e trabalhos realizados
- Tecnologias que utilizo
- Formas de contato

---

## 🛠 Tecnologias Utilizadas

- **HTML5** – Estrutura das páginas
- **SASS** – Estilização e responsividade

Meu objetivo é continuar aprimorando este portfólio, adicionando novos projetos, otimizando seu desempenho e tornando-o cada vez mais atraente e funcional.
